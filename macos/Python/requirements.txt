# Wheels embedded in Jetlink.app, pinned by version and by hash.
# Versions come from 01-contracts.md section 1; they are the ones measured on
# the bench. Installed with --no-deps, so every transitive dependency is listed
# here explicitly.
#
# To regenerate after a version bump, with any Python that can reach PyPI:
#
#   pip download --no-deps --only-binary=:all: --dest /tmp/wheels \
#     onnxruntime==<v> numpy==<v> onnx==<v> libusb1==<v> protobuf==<v> \
#     ml_dtypes==<v> typing_extensions==<v> flatbuffers==<v> packaging==<v>
#   pip hash /tmp/wheels/*.whl
#
# Two rules for the hash lines:
#   1. Record a hash for every file pip may pick on cp314 macOS arm64, not just
#      the one it picks today. numpy and protobuf ship more than one candidate
#      (a platform wheel and a wider one); if only one hash were listed, a pip
#      that ranked the other higher would fail with --require-hashes.
#   2. Keep the "wheel:" comment above each requirement pointing at the exact
#      file embed-python.sh prefetches with curl. The script greps those URLs;
#      it installs with --no-index --find-links so the build is hermetic and
#      the download cache is reused between runs.
